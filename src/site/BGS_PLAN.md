# Bangladesh and Global Studies (BGS): visualization plan

Subject key `bgs`. Book: NCTB Class 9–10 *Bangladesh and Global Studies* / *বাংলাদেশ ও বিশ্বপরিচয়* (2026 edition, 15 chapters).
Status on 2026-10-05: chapters 3, 4 and 5 are built (39 lessons, EN + BN). The other twelve chapters appear on the
subject page as "coming soon" and have a provisional plan below.

## How a BGS lesson is built

Learning order: **Read → Visualize → Understand → Organize → Remember**. On the page that becomes:

| Master-prompt part | Section in `content/bgs/chNN.txt` | Notes |
| --- | --- | --- |
| Topic overview | `## what` | two or three sentences |
| Visual explanation | `@visual <widget>` + `## visual` (one-line "how to use it") | shown right after the overview (BGS only) |
| Easy explanation | `## simple` | two short paragraphs, an everyday picture |
| Main points | `## points` | numbered `1. **Heading:** text`; tables as lines starting with `|`; `> ` asides for gentle book corrections |
| (definitions) | `## definition` | exam-ready wording |
| (why it happens) | `## why` | optional, only where there is a real "why" |
| Why is it important? | `## matters` | three bullets |
| (key terms) | `## terms` | `term (other language) | meaning` |
| Important facts | `## facts` | `label | value` |
| (calculation) | `## formula`, `## example` | only for lessons with arithmetic (time, antipode, tides, waterways) |
| (misconceptions) | `## mistakes` | `x` wrong / `v` right pairs |
| Quick revision | `## remember` | five bullets |
| (reflection) | `## think` | one open question |
| Check your understanding | `## quiz` | three questions; same answer positions in EN and BN |

Rules that were followed and should be kept:

- Lesson ids are the book's section number plus a running sub-id (`3.1` → `3.1.1 … 3.1.4`), because the book's sections are long.
- Nothing is copied verbatim from the book. Figures and place names are the book's; where the book is wrong or the two
  editions disagree, the lesson says so in a short `> ` aside and still tells the student what to write in the exam.
- English and Bangla carry the same content, section for section.
- Wide tables scroll sideways on phones with the first column pinned; a hint appears automatically.

## Map data and accuracy

All map geometry is generated by `geo/build_geo.py` into `geo/geo-bd.json`, `geo-world.json`, `geo-sasia.json`
(copied to `public/data/` by `build_site.py` and loaded only when a map widget needs it).

| Layer | Source | Licence |
| --- | --- | --- |
| Bangladesh districts (64, dissolved from upazilas) | geoBoundaries gbOpen BGD ADM3 (BBS / OCHA ROAP) | CC BY 4.0 |
| Neighbouring countries, coast, rivers, cities, International Date Line | Natural Earth | public domain |
| Plate boundaries | Bird (2003), PB2002 | ODC-By / PDDL |

- No coordinates, borders or river courses are invented. Rivers that Natural Earth does not contain (Pasur, Sangu, Feni,
  Naf, Matamuhuri …) are **not** drawn as lines; the map marks the places the textbook names on their route.
- Maps that colour whole districts because the textbook lists districts (landforms, forests, seismic zones, thinly peopled
  areas) carry a visible "Schematic" note.
- The South Asia map notes that some boundaries in the dataset are disputed.
- Every map shows its attribution line under the map.
- A district-level population-density map was planned for 4.1.3 but left out: it needs district figures from the
  2022 census, and those were not available from an approved source during the build. Add it when the owner supplies the table.

## Adding the next chapter

1. Get the chapter's pages from both editions (the PDFs have no text layer; OCR is needed).
2. Add `T` lines in `src/map/bgs.txt`, friendly Bangla titles in `src/map/friendly_bn.py`, run `python3 build_map.py`.
3. Write `src/site/widgets_bgsNN.js` using the toolkit in `widgets_bgs00.js` (`window.G`: `bdMap`, `worldMap`, `sasiaMap`,
   `flow`, `stepper`, `chips`, `tiles`, `bars`, `legend`, `card`, `list`).
4. Write `src/site/content/bgs/chNN.txt` in the section order above.
5. `python3 build_site.py`, run `check.js` on every new page in both languages, screenshot the widgets, then push.
